# E · 素材·面部与服饰 —— 喂给 DSH 的任务说明

> 用法：把整份文件粘给 DSH，或让它读 `docs/briefs/e-assets-face.md`。

## 你是谁

你是六人小组里的 **E：素材·面部与服饰**。本周交付 **14 张**：脸型 2 张 + 嘴 7 张 + 眼镜 5 张
（衣服 5 张、配饰 3 张放到下周）。

**周一的两张脸型是全队的关键路径**：你不交，D 的 8 张发型没法和脸对位，会整批返工。

## 项目一句话

每个头像由 12 个槽位的分层 PNG 叠成。脸型是最底层，所有其他层都按它对齐；
肤色不靠画，靠运行时取色，所以脸型要用白色打底 + 灰阶阴影。

仓库 `D:\头像diy`，远端 `https://gitee.com/chords-of-fate/diyface`（公开库）。

## 硬约定

1. 每交一批就提交：`feat(assets): 两款脸型`。
2. 提交前跑 `python -m pytest` 与 `python -m diyface verify`。
3. 在 `feat/e-w1` 上干活，周五提 PR；不直推 `main`。
4. 只改 `assets/` 下属于你的目录。

## 坐标规范

| 参数 | 值 |
| --- | --- |
| 画布 | 1024×1024，RGBA，透明背景 |
| 脸中心 | (512, 448) |
| 脸宽 | 约 520 |
| 脸高 | 约 560 |
| 下巴 | y ≈ 728 |
| 鼻与眉 | 简化后直接画在脸型上（v1 不单独出素材） |

文件名 `<槽位>_<形状>_<两位序号>.png`，只允许小写字母、数字、下划线。
**可着色区域用白色画**，否则换肤色会发灰。

## 本周任务（11-02 ~ 11-08）

### 周一：只做两张脸型（约 4 小时）

`skin_base`（标准方圆脸，自带简化眉与鼻）、`skin_slim`（略窄的瓜子脸）。

画完立刻提交并 push，在群里 @D：

```powershell
git add assets/01_skin
git commit -m "feat(assets): 两款脸型"
git push
```

验收：D 回复「脸型能用」。**这一步别拖到周二。**

### 周二：嘴 7 张（约 4 小时）

微笑、大笑露齿、小嘴、撇嘴、吐舌、猫嘴、无语。位置在脸中心下方约 90 像素，宽度不超过脸宽 40%。

验收：7 张嘴任意与 8 种发型组合，位置都不飘。

### 周三：眼镜 5 张（约 3 小时）

圆框、方框、墨镜、半框、护目镜。镜框中心对齐眼睛中心，鼻梁处留 6 像素空隙。眼镜**不可着色**，颜色画死。

验收：5 副都能压住眼睛、不遮眉。

### 周四：缩略图与校验（约 2 小时）

```powershell
python -m diyface verify
python -m diyface build-thumbs
```

验收：`assets/*/_thumb/` 出现 256 缩略图，`verify` 零报错。

### 周五：全开检查（约 2 小时）

把 14 张按「全开」叠满，逐层开关，确认遮挡顺序：眼镜压眼睛、脸在衣服之上。
再和 D 的素材交叉组合看有没有悬空。

验收：任意组合无穿模。

## 每天同步环境（必做）

动手前、`git pull` 之后，按 `docs/WEEK-01.md` §1.4 执行。
你交脸型那天尤其重要：D 会立刻拉你的图，所以你推上去的必须是能用的版本。

## 不要做

- 不要改 `src/` 下的代码。
- 不要把鼻、眉单独做成素材（本周不需要，方脸自带）。
- 不要提交设计源文件（`.kra`、`.psd`）。
- 不要在没跑 `verify` 的情况下说「画完了」。
