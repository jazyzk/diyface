# E · 素材·下半身与配饰 —— 喂给 DSH 的任务说明

> 用法：把整份文件粘给 DSH，或让它读 `docs/briefs/e-assets-face.md`。

## 你是谁

你是六人小组里的 **E：素材·下半身与配饰**。负责脸型、服装、嘴、眼镜、配饰五类共 **23 张**分层 PNG。

**周一的两张脸型是全队的关键路径**：你不交，D 的前发没法和脸对位，会整批返工。

## 项目一句话

每个头像由 10 个槽位的分层 PNG 叠成。脸型是最底层，所有其他层都按它对齐；
肤色不靠画，靠运行时取色，所以脸型要用白色打底 + 灰阶阴影。

仓库 `D:\头像diy`，远端 `https://gitee.com/chords-of-fate/diyface`（公开库）。

## 硬约定

1. 每交一批就提交：`feat(assets): 两张脸型`。
2. 提交前跑 `python -m pytest` 与 `python -m diyface verify`。
3. 在 `feat/e-w1` 上干活，周五提 PR；不直推 `main`。
4. 只改 `assets/` 下属于你的目录。

## 坐标规范

| 参数 | 值 |
| --- | --- |
| 画布 | 1024×1024，RGBA，透明背景 |
| 脸中心 | (512, 500) |
| 头顶 | y = 170 |
| 眼睛线 | y = 460 |
| 嘴线 | y = 620 |
| 肩线 | y = 880 |

文件名 `<槽位>_<形状>_<两位序号>.png`，只允许小写字母、数字、下划线。
**可着色区域用白色画**，否则换肤色会发灰。单张不超过 **80KB**。

## 本周任务

### 周一：只做两张脸型（约 4 小时）

画完立刻提交并 push，在群里 @D：

```powershell
git add assets/01_skin
git commit -m "feat(assets): 两款脸型"
git push
```

验收：D 回复「脸型能用」。**这一步别拖到周二。**

### 周二：服装 6 张（约 4 小时）

领口上缘接住下巴（y≈800），下摆压到肩线 y=880 附近。

### 周三：嘴 7 张（约 3 小时）

位置在嘴线 y=620 附近，宽度不超过脸宽 40%。

### 周四：眼镜 5 张 + 配饰 3 张（约 3 小时）

镜框中心对齐眼睛线 y=460，鼻梁留 6 像素空隙；配饰左右对称、避开中线。

```powershell
python -m diyface verify
python -m diyface build-thumbs
```

### 周五：全开检查（约 2 小时）

把 23 张按「全开」叠满，逐层开关，确认遮挡顺序：眼镜压眼睛、脸在服装之上、后发在脸之下。

验收：任意组合无穿模；`verify` 零报错。

## 每天同步环境（必做）

动手前、`git pull` 之后，按 `docs/WEEK-01.md` §1.4 执行。
你交脸型那天尤其重要：D 会立刻拉你的图，所以你推上去的必须是能用的版本。

## 不要做

- 不要改 `src/` 下的代码。
- 不要把鼻、眉单独做成素材（本期眉毛归 D，鼻直接画在脸型上）。
- 不要提交设计源文件（`.kra`、`.psd`）。
- 不要在没跑 `verify` 的情况下说「画完了」。
