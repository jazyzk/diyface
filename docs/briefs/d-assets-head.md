# D · 素材·头部 —— 喂给 DSH 的任务说明

> 用法：把整份文件粘给 DSH，或让它读 `docs/briefs/d-assets-head.md`。

## 你是谁

你是六人小组里的 **D：素材·头部**。本周交付 **16 张**分层 PNG：发型 8 张 + 眼睛 8 张（帽子 5 张放到下周）。
你不写代码，但必须让 `python -m diyface verify` 通过。

## 项目一句话

每个头像由 12 个槽位的分层 PNG 叠成，按 z 序合成。头部素材（头发、眼睛、帽子）画在 1024×1024 透明画布上，
所有图层共用同一套坐标，叠起来才不会「浮空」。

仓库 `D:\头像diy`，远端 `https://gitee.com/chords-of-fate/diyface`（公开库）。

## 硬约定

1. 每交一批就提交：`feat(assets): 发型补齐 8 张`。
2. 提交前跑 `python -m pytest` 与 `python -m diyface verify`，报错要修到干净。
3. 在 `feat/d-w1` 上干活，周五提 PR；不直推 `main`。
4. 只改 `assets/` 下属于你的目录，别动别人交的图。

## 坐标规范（画错会全组返工）

| 参考线 | 位置 | 作用 |
| --- | --- | --- |
| 垂直中线 | x = 512 | 左右对称 |
| 脸中心 | y = 448 | 眼睛围绕它排布 |
| 头顶基线 | y = 256 | 头发与帽子的起点 |

画布 1024×1024、RGBA、透明背景。文件名 `<槽位>_<形状>_<两位序号>.png`，只允许小写字母、数字、下划线。

**可着色素材必须用白色打底**：渲染器用「相乘」上色，白色乘任何颜色等于该颜色；
如果你用深棕画发丝，换色后会发灰甚至变黑。

## 本周任务（11-02 ~ 11-08）

### 周一：参考线与 3 张试作（约 4 小时）

`.venv\Scripts\Activate.ps1` 后运行 `python scripts/make_guide.py` 生成 `assets/_guide.png`（下划线开头，不会被当成素材）。
画 3 张：直发、圆眼、贝雷帽（帽子本周不交，只用来对位置）。

验收：把三张图交给 A 叠到脸型上，头发贴头皮、帽子不遮眼。

### 周二：发型补到 8 张（约 4 小时）

直发、微卷、双马尾、齐刘海、碎发、短寸、丸子头、光头。每画完 3 张跑一次 `python -m diyface verify --slot bangs`。

验收：8 张齐全，尺寸、命名、透明区零报错。

### 周三：眼睛补到 8 张（约 4 小时）

圆、细长、笑、星星、眯、惊讶、睡眼、异色瞳。眼睛是**不可着色**槽位，颜色直接画死，不需要 `_tint.png`。

验收：换发色时眼睛颜色不变。

### 周四：修校验问题（约 3 小时）

```powershell
python -m diyface verify
python -m diyface build-thumbs --slot eyes
```

缺 `_tint.png` 的补一张全白蒙版（表示整层都可着色）：

```powershell
python -c "from PIL import Image; Image.new('RGBA',(1024,1024),(255,255,255,255)).save('assets/02_bangs/bangs_straight_01_tint.png')"
```

验收：`verify` 零报错。

### 周五：与 E 交叉验收（约 2 小时）

把你的 16 张套在 E 的两张脸型上逐张看：有没有露白边、帽子与刘海谁该在上、左右是否对称。

验收：任意组合无露白、无穿模。

## 每天同步环境（必做）

开始画之前、`git pull` 之后，按 `docs/WEEK-01.md` §1.4 走一遍。
你尤其要注意第 5 步：别人交了新素材，缩略图要重建，否则前端素材格是旧图。

## 不要做

- 不要改 `src/` 下的任何代码（发现工具不好用，告诉 A）。
- 不要用深色画可着色区域（换色会发灰）。
- 不要把 `.kra`、`.psd`、`.aseprite` 源文件提交进仓库。
- 不要为了「好看」改坐标：所有层必须共用同一套参考线。
