# D · 素材·上半身 —— 喂给 DSH 的任务说明

> 用法：把整份文件粘给 DSH，或让它读 `docs/briefs/d-assets-head.md`。

## 你是谁

你是六人小组里的 **D：素材·上半身**。负责前发、后发、眼睛、眉毛、帽子五类共 **31 张**分层 PNG。
你不写代码，但必须让 `python -m diyface verify` 通过。

## 项目一句话

每个头像由 10 个槽位的分层 PNG 叠成，按 z 序合成。头部素材画在 1024×1024 透明画布上，
所有图层共用同一套坐标，叠起来才不会「浮空」。

仓库 `D:\头像diy`，远端 `https://gitee.com/chords-of-fate/diyface`（公开库）。

## 硬约定

1. 每交一批就提交：`feat(assets): 前发补齐 8 张`。
2. 提交前跑 `python -m pytest` 与 `python -m diyface verify`，报错要修到干净。
3. 在 `feat/d-w1` 上干活，周五提 PR；不直推 `main`。
4. 只改 `assets/` 下属于你的目录，别动别人交的图。

## 坐标规范（画错会全组返工）

| 参考线 | 位置 | 作用 |
| --- | --- | --- |
| 垂直中线 | x = 512 | 左右对称 |
| 头顶基线 | y = 170 | 头发与帽子的起点 |
| 眼睛线 | y = 460 | 眼珠中心 |
| 脸中心 | y = 500 | 五官围绕它排布 |

画布 1024×1024、RGBA、透明背景。文件名 `<槽位>_<形状>_<两位序号>.png`，只允许小写字母、数字、下划线。
单张体积不超过 **80KB**。

**可着色素材必须用白色打底**：渲染器用「相乘」上色，白色乘任何颜色等于该颜色；
如果你用深棕画发丝，换色后会发灰甚至变黑。

## 本周任务

### 周一：参考线与 3 张试作（约 4 小时）

```powershell
.venv\Scripts\Activate.ps1
python scripts/make_guide.py --reference assets/01_skin/skin_base.png
```

生成 `assets/_guide.png`（下划线开头，不会被当成素材）。画 3 张：直发、圆眼、贝雷帽。

验收：把三张图交给渲染负责人叠到脸型上，头发贴头皮、帽子不遮眼。

### 周二：前发补到 8 张（约 4 小时）

每画完 3 张跑一次：

```powershell
python -m diyface verify --slot hair
```

验收：8 张齐全，尺寸、命名、透明区零报错。

### 周三：后发 6 张 + 眉毛 4 张（约 4 小时）

后发要压在服装之上、脸之下；眉毛贴合眼睛线（y≈420–445）。

### 周四：眼睛 8 张 + 帽子 5 张（约 4 小时）

```powershell
python -m diyface verify
python -m diyface build-thumbs
```

缺 `_tint.png` 的补一张全白蒙版：

```powershell
python -c "from PIL import Image; Image.new('RGBA',(1024,1024),(255,255,255,255)).save('assets/04_hair/hair_straight_01_tint.png')"
```

### 周五：交叉验收（约 2 小时）

把你的 31 张套在 E 的脸型与服装上逐张看：有没有露白边、帽子与前发谁该在上、左右是否对称。

验收：任意组合无露白、无穿模；`verify` 零报错。

## 每天同步环境（必做）

开始画之前、`git pull` 之后，按 `docs/WEEK-01.md` §1.4 走一遍。
别人交了新素材，缩略图要重建，否则前端素材格是旧图。

## 不要做

- 不要改 `src/` 下的任何代码（发现工具不好用，告诉渲染负责人）。
- 不要用深色画可着色区域（换色会发灰）。
- 不要把 `.kra`、`.psd`、`.aseprite` 源文件提交进仓库。
- 不要为了「好看」改坐标：所有层必须共用同一套参考线。
