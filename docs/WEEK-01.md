## 9 卡住了怎么办

| 现象 | 先查 | 找谁 |
| --- | --- | --- |
| 测试红了 | 读失败用例名与断言信息 | 对应模块负责人，P6 兜底 |
| 素材叠起来浮空 | 参考线与命名 | P1 与 P2 |
| 页面不更新 | Network 面板看状态码 | P3 与 P4 |
| 接口 422 | 错误 `code` 与 `field` | P4 |
| 合并冲突 | 冲突文件与 `<<<<<<<` 标记 | 队长 |
| 环境装不上 | 镜像地址、Python 版本 | P6 |

拿不准就在群里贴「命令 + 完整报错」，别只贴一句「跑不起来」。

## 10 每天同步环境

`git pull --rebase` 之后（冲突时先 `git rebase main`）、开始写代码或画图之前，按 `docs/ONBOARDING.md` §2 走一遍：

```powershell
.venv\Scripts\Activate.ps1
python -m pytest
python -m diyface verify
git switch -c feat/<你的域>-w1d3
```

别人交了新素材，缩略图要重建，否则前端素材格是旧图。
